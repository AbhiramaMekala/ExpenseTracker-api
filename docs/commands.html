Expense Tracker API commands

Every terminal command for the API, from starting the server to reading the database. All 62 outputs marked “Output” were recorded by running the command against the real server on an empty database on 9 October 2026, so your ids, timestamps and totals will differ.

Terminal 1: the API
$ uvicorn app.main:app --reload

Serves http://127.0.0.1:8000 and prints one line per request it receives.

Terminal 2: the front-end
$ python3 -m http.server 5500 --directory frontend

Serves the web page at http://127.0.0.1:5500. The page calls the API from your browser.

Terminal 3: you, with curl
$ curl -s http://127.0.0.1:8000/expenses

Sends requests by hand. Everything on this page from “Check the server” on runs here.

Start the API

Run these once per session in Terminal 1. Leave the server running; every other command talks to it.

Go to the project folder

cd ~/Downloads/expense-tracker-api

Turn on the virtual environment

Your prompt starts with (.venv) when it is active.

source .venv/bin/activate

Install or update the packages

pip install -r requirements.txt

--reload restarts the server whenever you save a file. Stop it with Ctrl+C.

POST /expenses

Bad input is rejected with 422 Unprocessable Content and nothing is saved. Shape and type problems come back as a list from Pydantic; business-rule problems come back as one sentence.

A browser call from the front-end is allowed

A call from any other site is not

Look inside the database

The API stores everything in one SQLite file, data/expenses.db. scripts/sql.py runs any query and prints a table. macOS also ships the sqlite3 tool, shown last.

Tables in the database

python3 scripts/sql.py --tables
Output1 line
expenses

How the expenses table is defined

python3 scripts/sql.py --schema
Output12 lines
CREATE TABLE expenses (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    title        TEXT    NOT NULL,
    amount_cents INTEGER NOT NULL CHECK (amount_cents > 0),
    category     TEXT    NOT NULL,
    spent_on     TEXT    NOT NULL,          -- ISO date, YYYY-MM-DD
    note         TEXT,
    created_at   TEXT    NOT NULL DEFAULT (datetime('now')),
    updated_at   TEXT    NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX idx_expenses_spent_on ON expenses (spent_on);
CREATE INDEX idx_expenses_category ON expenses (category);
